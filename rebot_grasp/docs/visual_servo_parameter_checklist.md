## 2. 启动与模式切换流程

| 阶段 | 电机模式 | 行为 |
|---|---|---|
| 程序启动 | MIT 重力拖动 | `pos=q, Kp=2, Kd=1, tau=g(q)`，用户手动拖到安全工作位置 |
| 目标连续确认 3 帧 | MIT 位置伺服 | 锁定当时 TCP 姿态和位置参考，自动跟随 |
| 短暂掉帧 | MIT 位置伺服 | 不使用旧视觉误差，按加速度上限减速 |
| 确认丢失 | MIT 重力拖动 | 停止位置跟随，重新允许手动拖动 |
| 再次确认目标 | MIT 位置伺服 | 从新的真实 TCP 位姿重新开始跟随 |

运行期间不执行固定初始位姿，也不反复切换电机模式；只有用户正常退出时，
才从 MIT 切到 POS_VEL 回 home，随后立即失能并断开。

## 3. 重力补偿拖动参数

```text
q_command = q_actual
tau_ff = g(q_actual)
tau_motor = Kp · (q_command - q_actual) - Kd · qd + tau_ff
```

| 参数 | 当前值 | 说明 |
|---|---:|---|
| MIT `pos` | 当前实测 `q` | 每周期更新，因此不会把机械臂拉回旧位置 |
| MIT `Kp` | `2.0` | 与项目旧重力补偿样例一致 |
| MIT `Kd` | `1.0` | 与项目旧重力补偿样例一致 |
| MIT `tau` | 原始 `g(q)` | 不使用 joint2/3 经验缩放 |
| 反馈读取 | MIT 回复缓存 + `20 Hz` 主动请求 | 保持反馈更新，同时避免每周期六轴轮询把控制降到约 110 Hz |
| 角度连续化 | 相对上一帧做 `±2π` unwrap | 防止编码器跨边界产生虚假大位置误差 |
| 总扭矩上限 | `[9,9,9,3,3,3] N·m` | 重力前馈、阻尼和位置项的估算合计不得超过连续额定值 |

## 4. 自动跟随参数

视觉外环：

```text
e_cam  = p_target_cam - p_desired_cam
v*     = clamp(Kp · deadband(e_cam), v_max)
Δv     = clamp(v* - v, a_max · dt)
p_ref  = p_ref + v · dt
```

| 参数 | 当前值 | 保守首测建议 A | 平衡建议 B | 作用 |
|---|---:|---:|---:|---|
| 跟随距离 | `0.40 m` | `0.40 m` | `0.40 m` | 目标与相机期望距离 |
| 位置增益 `Kp` | `0.65 s⁻¹` | `0.45 s⁻¹` | `0.65 s⁻¹` | 越大响应越快，也更易抖动 |
| 位置死区 | `0.005 m` | `0.008 m` | `0.005 m` | 目标进入死区后不继续修正 |
| 最大线速度 | `0.008 m/s` | `0.005 m/s` | `0.008 m/s` | 当前为 8 mm/s |
| 最大线加速度 | `0.025 m/s²` | `0.015 m/s²` | `0.025 m/s²` | 当前从 0 到最大速度约 0.32 s |
| IK 关节目标速度 | `0.30 rad/s` | `0.20 rad/s` | `0.30 rad/s` | 限制相邻 IK 关节目标变化 |
| IK 关节目标加速度 | `0.70 rad/s²` | `0.40 rad/s²` | `0.70 rad/s²` | 已实现，避免关节目标速度突变 |
| 相对本次伺服起点最大位移 | `0.06 m` | `0.04 m` | `0.06 m` | 每次重新捕获都会重置；不是碰撞检测 |
| 参考领先真实末端 | `0.02 m` | `0.01 m` | `0.02 m` | 防止 IK/机械臂跟不上时积累 |

## 5. 回 home 参数

| 参数 | 当前值 | 保守首测建议 A | 平衡建议 B | 备注 |
|---|---:|---:|---:|---|
| home 关节角 | 全部 `0 rad` | 不变 | 不变 | 需保证回程无障碍 |

| 最大关节速度 | `0.22 rad/s` | `0.15 rad/s` | `0.22 rad/s` | 回程采用最小 jerk 轨迹 |
| 最大关节加速度 | `0.50 rad/s²` | `0.30 rad/s²` | `0.50 rad/s²` | 已实现 |

## 6. 控制内环与故障阈值

| 参数 | 当前值 | 建议 | 说明 |
|---|---:|---:|---|
| MIT 控制频率 | 约 `500 Hz` | 保持 | 用户日志实测约 485 Hz |
| 伺服 MIT `Kp` | 每轴 `8.0` | 首轮保持 | 只在目标确认后的视觉跟随中使用 |
| 伺服 MIT `Kd` | 每轴 `1.0` | 首轮保持 | 只在目标确认后的视觉跟随中使用 |
| 拖动 MIT `Kp/Kd` | `2.0 / 1.0` | 与旧样例一致 | 启动和确认丢失后使用，`pos` 每周期等于当前 `q` |
| 反馈速度故障阈值 | `2.0 rad/s` | 保持 | 这是停机阈值，不是命令速度 |
| 到位位置容差 | `0.025 rad` | 保持 | 后续根据编码器噪声再收紧 |
| 到位速度容差 | `0.06 rad/s` | 保持 | 与稳定时间共同判断 |
| 连续稳定时间 | `0.30 s` | 保持 | 防止瞬间经过目标即判定到位 |
| 到位超时 | `5.0 s` | 保持 | POS_VEL 回 home 的最终稳定等待上限 |
